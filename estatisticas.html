Como a contagem funciona

O site registra uma visualização de página a cada carregamento. Para evitar que cada clique interno seja tratado como uma nova pessoa, o navegador mantém um identificador local simples e o horário da última visita.

Ativação necessária

O contador já está implementado no projeto. Para começar a registrar acessos, crie duas variáveis de ambiente na Vercel:

COUNTERAPI_WORKSPACE COUNTERAPI_TOKEN

Depois de salvar as variáveis, faça um novo deploy. O token fica somente no servidor e não é exposto no HTML.
