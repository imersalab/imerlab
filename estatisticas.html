Como a contagem funciona

O ImersaLab usa o Web Analytics da própria Vercel. A Vercel contabiliza visitantes e visualizações de página de forma agregada e sem cookies tradicionais. O identificador anônimo de visitante é renovado diariamente.

Ativação necessária

Para exibir os números nesta página:

1. Ative Analytics → Web Analytics no projeto da Vercel e faça um novo deploy.

2. Crie um Access Token da Vercel e salve em Settings → Environment Variables com o nome:

VERCEL_ANALYTICS_TOKEN

O ID do projeto é obtido automaticamente por VERCEL_PROJECT_ID. Se o projeto pertencer a um time e a API pedir o escopo do time, adicione também:

VERCEL_TEAM_ID

Depois salve e faça Redeploy. O token fica somente na função serverless e não é enviado ao navegador.
